注音校對工具 v5.6.2 升級與續作方式

一、目前這份三上校對不需重跑整批 PDF
1. 保留原本的「注音校對_輸出」資料夾，不要刪除或改放空資料夾。
2. 啟動 v5.6.2。
3. 在「校對專案資料夾」選擇原本的「注音校對_輸出」。
4. 按「修復／更新報告」。

程式會保留原 session_id、人工/GPT 判定與專案 actual 證據。相同 PDF、actual 資產與專案 actual 證據均相容時，執行紀錄會顯示 actual reuse；只重建 expected 候選、回歸門檻與最終報告。

二、本版針對目前問題的修正
- 「轉動」依已確認規範使用ㄓㄨㄢˇ，強制回歸不再被錯誤的三上廣泛例外規則阻擋。
- 15 筆未綁定舊 PDF SHA-256 的三上歷史頁碼案例仍保留稽核，但列為 NOT_APPLICABLE，不列入目前教材版本的完成分母。
- actual 待判定為 0 時，按「輸出 actual 待判定給 GPT」只顯示無須匯出的訊息，不會再出現 traceback。
- 待處理為 0 但完成門檻未通過時，主畫面會顯示失敗門檻名稱。

三、不必重做的項目
- 不必重新匯入先前已成功寫入的 232 筆判定。
- 不必重新輸出 actual GPT 判定包。
- 不必另建新的「注音校對_輸出」。

只有 PDF bytes、actual 核心資料或專案 actual 證據真的改變時，程式才會重解碼受影響的 PDF；這屬安全檢查，不是本次升級的正常預期流程。
