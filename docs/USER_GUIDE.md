# 使用指南

臺灣國小教材 PDF 注音校對工具（內部使用）。

第一次使用：執行「安裝依賴.bat」。

平常使用：執行「啟動_單機注音校對.bat」。

## 一、一般校對流程

1. 第一次處理一本教材：選「教材 PDF／資料夾」與「校對專案資料夾」，按「開始新校對」。
2. 之後回到同一個「校對專案資料夾」，直接按「繼續校對」。不要為了繼續人工確認而重跑完整流程。
3. 人工確認畫面只顯示校對需要的資訊：課本頁、詞語／局部詞境、所在句、目標字、課本目前注音、應標注音與問題原因。occurrence_id、review_id、state、hash 等技術資料預設隱藏在「更多…→查看／隱藏技術資訊」。
4. 人工處理後或由 v5.6.1 升級時，按主畫面的「修復／更新報告」。程式會先驗證相同 PDF 與 actual 證據；相容時直接 reuse actual，只更新候選、完成門檻與 Excel 報告。
5. 「查看報告」開啟日常使用的「注音校對_最終報告.xlsx」；「更多…→開啟技術稽核報告」才會開啟完整治理資料。
6. 主畫面的詳細「執行紀錄」預設隱藏；平常只顯示一行進度，需要除錯時再從「更多…」展開。

## 二、教材人工驗收

主畫面的「目前專案」會說明處理階段、尚待處理的筆數與下一步。
待處理筆數按各位置的狀態計算，同一位置同時缺目前注音與應標注音時只算一筆。
「進度詳細資訊（可複製）」保留原始門檻、錯誤及診斷；只有原有完成檢查通過才顯示全冊完成。
無法讀取或確認狀態時，先重新讀取專案狀態，必要時使用「修復／更新報告」。

「繼續校對」依序處理「應標注音待確認」和「課本目前注音待辨識」。
每組把相同目標字集中，字群順序固定按原教材首次出現的位置；同字內保留教材順序。
每個位置仍須個別保存，不同語境、讀音與異體字不會自動套用答案。
「本組此字剩餘」包含本筆，不包含稍後處理；「重新查看稍後處理」可把暫略項目放回清單。
actual 已暫存仍不會隱藏同筆尚未確認的應標注音，暫存後須另按「套用 actual 修正」。
本筆 actual 有效暫存且應標已確認時，舊 actual 的差異會暫列「等待套用後重新比較」，並接續下一筆。
底部顯示待套用的修正組數、實際勾選的位置數及等待重新比較筆數；同組未勾選的位置仍保留待辦。
同一 exact 字形逐筆確認相同讀音時，會保留仍有效的先前勾選，再加入本次明確勾選的位置；不會自動勾選其餘同字。
若新輸入與該組既有暫存讀音不同，會阻止保存並保留原暫存，須先釐清既有暫存後再重新核對；不會替舊位置改判讀音。
等待套用不等於完成；沒有其他可處理項目時，請按「套用 actual 修正」，由實際套用結果重新比較。
仍有差異者會回到差異確認，一致者依原規則處理；不會自動確認教材錯誤。

**確認教材錯誤：** 當本筆課本現標與獨立應標證據已明確不同，按主畫面的「確認教材錯誤」即保存本筆明確人工確認。成功後接續下一筆；不再逐項勾選或另開第二次確認視窗。每次只確認目前這一筆。保存失敗、來源或證據改變時，原筆保留待處理。保存應標判定本身不會自動確認教材錯誤。

舊版已保存的六閘門紀錄仍按原六項及證據條件嚴格讀取，不會自動轉成新的 GUI 確認紀錄。

Excel／GPT 外部匯入仍須遵守原有六閘門確認契約；填入新 GUI 模式名稱，無法代替本筆在主畫面的人工操作及其證據紀錄。

保存應標時若 actual 尚待套用，會提示「應標注音已保存，目前注音套用後再比較」。
此時上方目前注音是套用前結果，請用「輸入其他應標注音」依語境判定；一鍵確認在沒有本筆待套用 actual 時維持可用。
來源、完整性或暫存驗證失敗仍會保留待辦及錯誤說明；儲存失敗不跳筆。
關閉再開啟可恢復有效暫存。若 actual 已提交但後續更新失敗，請按「繼續 actual 更新（已提交）」恢復，
既有交易會保留人工 expected，且不會重新套用已提交的暫存。
歷史暫存只接受能與目前群組或 sealed 工作階段原狀態精確核對的快照；無法重建者仍拒絕套用，須保留原資料並處理其診斷。

原頁預覽及 actual 各樣本使用自己的位置外框；框線只供介面定位，不寫入 PDF 或原始證據圖片。
外框跟隨圖片縮放及旋轉，頁邊外的區域只標示頁內部分。
圖片依可用寬度等比例顯示，主畫面預覽會使用摘要與操作按鈕間的剩餘高度；
較高的圖片可在預覽內捲動。首次顯示與換筆會定位到紅框，手動捲動後重繪不會拉回。
視窗調整大小後會重新從 PDF 渲染清晰圖片；actual 多樣本完整展開，使用右側表單捲軸
或滾輪查看其他樣本及下方輸入欄位。預覽捲到底後，滾輪可接續捲動外層長表單。
位置缺失、無效或圖片讀取失敗時會清除舊框並提示原因；無法可靠定位的樣本不能直接確認。
應標注音的一鍵確認和文字依據選填維持原有操作，重用規則仍須另外建立。
人工校對畫面上方有「撤銷上一次判定」和「查看已確認項目」。保存應標判定後，即使該筆離開待辦，
可按「撤銷上一次判定」回到原位置，恢復此次保存前的判定；此前沒有人工判定時，回到未人工確認。
回到原位置重新輸入應標注音並成功保存後，畫面依更新後的待辦清單接續；保存失敗仍留在原筆。
「查看已確認項目」可按教材名稱、課本頁碼或文字／語境查找已保存的本筆應標判定。
選取後會在原頁預覽顯示該位置，可輸入其他應標注音、更正為目前注音，或透過「更多…」撤銷本筆人工判定；
「撤銷上一次判定」只針對最近一次成功保存的應標判定，查看或返回待辦不會更改撤銷目標。
「更多…」中的「返回待辦」回到原待辦清單。保存成功後清單會更新，重新開啟人工校對也能查到已保存項目。

按鈕會隨視窗寬度換成多列，說明會換行。長表單可用右側捲軸或滑鼠滾輪；
人工確認的保存／取消與主判定按鈕保留在固定底部。
長路徑和單行輸入有橫向捲軸，可用 Ctrl+A、Ctrl+C 複製完整值；詳細資訊也可一鍵複製。
