# v5.4.1 專案路徑自動修正熱修版 4

修正 GPT 匯入／更新報告等管理操作可能收到重複的 `注音校對_輸出\注音校對_輸出` 路徑，導致明明已有 `校對工作階段.json` 卻報 FileNotFoundError。

- CLI 管理操作：若指定路徑本身沒有工作階段，但相鄰且唯一的父／子專案資料夾已有工作階段，自動改用該資料夾。
- GUI：每 0.5 秒狀態更新時同樣校正「校對專案資料夾」欄位。
- 若指定路徑本身已有工作階段，永遠優先使用原路徑；不會覆寫或搬移任何專案資料。
- 路徑無法唯一判斷時不猜，維持原路徑並讓既有完整性檢查報錯。
- 不修改 actual decoder / expected resolver 資產，因此不為此熱修變更 actual/expected fingerprint。
